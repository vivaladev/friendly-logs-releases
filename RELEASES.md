# Что изменилось

## 1.0.7

Если Grafana отвечает 401 или 403, сервер входит ещё раз сам. Пароль остаётся в памяти процесса и на диск не пишется. Повторный вход делается один раз. Чтобы правка попала в контейнер, запустите сервер ещё раз.

## 1.0.6

Окно сохранения фильтра закрывается крестиком, кнопкой «Отмена», клавишей Esc и щелчком вне окна. После обновления лаунчер показывает изменения текущей версии. Это окно закрывается крестиком справа сверху. Чтобы правка фильтра появилась в интерфейсе, запустите сервер ещё раз: образ собирается заново.

## 1.0.5

Если macOS открыл скачанную копию, приложение само переносит себя в «Программы». Обновление из лаунчера больше не останавливается на защищённой временной папке. Сборка контейнера находит помощник Docker так же, как терминал macOS и консоль Windows.

## 1.0.4

Лаунчер, открытый из «Программ», находит Docker так же, как терминал macOS и консоль Windows.

## 1.0.3

Установленное приложение само собирает и запускает контейнер. Файлы сервера лежат внутри приложения.

## 1.0.2

Проверка обновлений работает, если путь к приложению содержит символическую ссылку. Приложение для macOS подписано как бандл и поставляется zip-архивом, не DMG.

## 1.0.1

Ссылка «В Grafana» открывает дашборд логов, а не главную страницу.

## 1.0.0

Первый выпуск для macOS (Apple Silicon) и Windows 11.
